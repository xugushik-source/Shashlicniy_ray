# Референс пламени: Ember & Bone

Источник: https://emberandbone.co.uk/ ; проверено 15.11.2026 через Firecrawl (branding, HTML, screenshot). Просмотрены пиксели верхнего экрана 1600×1050 из desktop-снимка 1920×14281. Мобильное воспроизведение и движение самого референса интерактивно не проверены; механизм подтверждён HTML/CSS.

Огонь — фоновое MP4 `heroVideo`, не рамка и не canvas. Крупный план стейка и огня с дымом; видео object-fit:cover, object-position:center 55%. CSS .hero-veil содержит градиент затемнения слева направо (92% → 12%) и снизу вверх; .hero-video — медленное scale 1.015–1.03 за 42 с. Два видео для мобильного варианта; muted/loop/playsinline, ленивое подключение src. Полупрозрачное зерно. Эти сведения извлечены из исходного HTML/CSS.

Референс: фон #0A0A0C, основной текст #F4F1EA, акцент #C9A227, Baskervville для крупных заголовков / Work Sans для основного текста (branding и CSS). В текущей правке сохраняется палитра магазина #0D0D0D/#F0ECE5/#A38D70 и текущая типографика. Оформление адаптируется только в пределах запроса о пламени, без замены каталога или фотографий товаров.

Реализация магазина: собственный лицензированный ролик гриля вместо медиа референса, постоянный фон по всему сайту, тёмные подложки карточек и форм. Исходник, лицензия, размеры и ограничения: docs/FIRE_MEDIA.md. Это стилистическое приближение, не точная копия кадров или всего дизайна.


# Движение фотографий: Motion Drive

Референс пользователя: https://motion-drive-harut3.vercel.app/ru . Проверен 15.11.2026. Firecrawl получил страницу Vercel Login, поэтому визуальные пиксели самого проекта не выдаются за просмотренные. Через подключённый read-only Vercel web_fetch_vercel_url прочитаны настоящий HTML, CSS 75fec110775d0fc0.css и клиентский page-088b7e16e38b4d56.js. Защита, настройки и файлы Motion Drive не менялись.

Подтверждённые приёмы в коде референса: hero-photo смещается по scrollY [0,1000] → [0%,18%]; вступительный текст opacity/y25 за 0.8 с; карточки opacity/y24 за 0.5 с с задержкой 0.08 на карточку; крупное фото film-img scale1.08 → 1 за 1.5 с; hover-фото scale1.025 за 0.5 с; reducedMotion=user.

В магазине это адаптировано нативными API без Framer Motion: ограниченный параллакс видимых фото/фонового видео, проявление карточек/заголовков по IntersectionObserver, каскад и сдвиг при переключении категорий, приближение при наведении. Дополнительно реализована отдельная витрина фотографий блюд: стрелки, клавиатура, горизонтальный свайп, смена кадров со сдвигом/растворением и медленным масштабом. Это дополнительная реализация по запросу пользователя, не утверждение о таком же слайдере на Motion Drive.

Витрина берёт реальные опубликованные фотографии из текущего каталога, без подмены карточек товара или фиктивных галерей одного блюда. Кнопка просмотра открывает соответствующий товар; ничего не добавляется в корзину автоматически. Интервал 6.5 с, явная пауза, остановка вне экрана/в скрытой вкладке/при фокусе/наведении. Reduced-motion отключает автоматическую смену, движение и плавный скролл, сохраняя ручное переключение. Анимации не определяют видимость контента: при отказе API карточки остаются доступными.
