# Общее правило пользователя для всех наших сайтов

- Формы заказа, регистрации и профиля должны поддерживать системное автозаполнение: корректные name/type/autocomplete, телефонная клавиатура и локализованные подписи.
- Контакты и адрес не заставлять вводить повторно. Сохранять черновик на устройстве, восстанавливать после перезагрузки и следующего визита, не затирать уже введённые или автозаполненные поля.
- Очистка корзины и завершение заказа не удаляют контактный профиль. Предусмотреть отдельное удаление сохранённых контактов/адреса.
- В проектах с авторизацией изолировать черновики по пользователю; синхронизацию между устройствами делать через защищённый профиль аккаунта. Не показывать данные предыдущего пользователя после смены аккаунта.
- Разные домены/браузеры не делят localStorage автоматически. Для единого заполнения между сайтами нужен общий вход и серверный профиль; не обещать такую синхронизацию без реализации.
- В контактном черновике не хранить платёжные реквизиты, пароли, секреты или токены. Проверять повреждённое/запрещённое хранилище; заказ должен оставаться доступен при отказе сохранения.
- Проверять восстановление формы, системные autocomplete-токены, отдельное удаление профиля и сохранение его при очистке корзины.
- Применять правило при работе над соответствующим сайтом; не менять остальные работающие проекты без задачи пользователя.
