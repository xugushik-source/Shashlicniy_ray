# Установка «Шашлычного рая» на главный экран

На первом экране и внизу магазина есть кнопка установки. В поддерживаемых браузерах она вызывает полученный beforeinstallprompt: браузер показывает своё системное подтверждение, сайт не может подтвердить установку за человека. Событие appinstalled скрывает предложение установки. Уже запущенное standalone-приложение не предлагает установку повторно.

Android Chrome/Edge/Samsung Browser обычно поддерживают этот механизм. На iPhone Safari кнопка открывает инструкцию «Поделиться → На экран Домой»: программного beforeinstallprompt там нет. Во встроенном Instagram/WebView при отсутствии события установки показывается честное пояснение, без редиректа или автоматического запуска другого браузера. Нельзя обещать установку одним кликом из любого встроенного браузера.

Проверено по MDN 15.11.2026: https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeinstallprompt_event — Limited availability; Safari/iOS и WebView не предоставляют API. Проверка доступности идёт по реальному событию, а не только User-Agent. User-Agent нужен лишь для текста подсказки.

Технически: четыре локализованных manifest, общий id=/, display=standalone, theme/background #0D0D0D, PNG 192/512, maskable 512 с отступами, Apple touch icon 180 и favicon 32. Стартовый URL сохраняет выбранный язык. Новый логотип с тремя шампурами и буквой Ш — сгенерированный фирменный знак; мастер branding/logo-master.png, рабочие размеры static/icons/.

Service worker кэширует только страницу отсутствия связи, её скрипт, CSS и значок. API, оформление заказов, платежи и личные данные не перехватываются и не кэшируются. При отсутствии сети магазин показывает информационную страницу; отложенной отправки заказов нет. Существующая локальная корзина сохраняется.

Проверки автоматические: manifest/MIME/размеры иконок, общая идентичность приложения, исключение API/POST из SW; native prompt и отказ Instagram/iPhone, отсутствие внешней навигации; очистка корзины, состояние суммы/счётчика и нового ключа идемпотентности. Установка на физическом телефоне не проверялась: соответствующий браузер текущему окружению недоступен.
