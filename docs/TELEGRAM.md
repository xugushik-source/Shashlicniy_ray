# Новый бот «Шашлычный рай»

Создание бота выполняется в официальном https://t.me/BotFather из Telegram-аккаунта владельца. В текущем подключении нет возможности управлять личным Telegram или общаться с BotFather от имени пользователя.

1. Открыть проверенный BotFather: https://t.me/BotFather .
2. Отправить `/newbot`.
3. Название: `Шашлычный рай | Ахалкалаки`.
4. Username предложить `ShashlichnyRayAkhalkalakiBot`. Доступность имени не проверена; BotFather сообщит, если оно занято.
5. Сохранить полученный токен как `TELEGRAM_BOT_TOKEN` в защищённом окружении проекта. Не отправлять токен в чат и не помещать в исходники.

`python3 telegram_setup.py` выполняет только getMe и сообщает публичное имя бота. Сообщения не рассылает, webhook не назначает. Инструкция проверена по https://core.telegram.org/bots/features#creating-a-new-bot .

Далее нужны публичный HTTPS endpoint отдельного проекта, проверка webhook secret, привязка владельца/поставщиков/курьеров, обработчик команд и гарантированная доставка outbox. Эти части пока не реализованы. В демо Telegram не рассылает заказы.

## Реализованный временный обработчик

`telegram_bot.py` отвечает на входящие личные сообщения и callback-кнопки: `/start`, `/menu`, `/contact`, `/language`. Четыре языка; категории и цены берутся из demo/catalog.json. Групповые сообщения игнорируются. Реальные заказы и оплаты не обрабатываются.

Запуск: `python3 telegram_bot.py`. Токен берётся из TELEGRAM_BOT_TOKEN либо вводится скрыто в терминале. Он не сохраняется в исходники. Для long polling нужен один постоянно работающий процесс с доступом к api.telegram.org. Существующий webhook программа не удаляет. Два локальных процесса защищены файловой блокировкой; offset хранится в игнорируемой data/telegram-offset.txt. Сохранение offset после обработки не гарантирует строго однократный ответ при аварийном завершении.

15.11.2026: getMe подтвердил @ShashlichnyRayAkhalkalakiBot; getWebhookInfo вернул отсутствие webhook; команды зарегистрированы, long polling запущен в текущей рабочей среде. Это не круглосуточный production-хостинг: после остановки среды процесс перестанет отвечать. Тесты проверяют старт, четыре языка, категории/цены, игнорирование групп и некорректные callback.
